# Retro Cassette Player

![Screenshot](https://raw.githubusercontent.com/LuxFer-498/retro-cassette-player/main/Screenshoot.png)

Pemutar musik desktop dengan tampilan kaset retro dan equalizer 10-band.

## Fitur

- Pemutar musik VLC backend (MP3, FLAC, WAV, OGG, M4A, OPUS, WMA)
- Visualizer bar real-time
- Equalizer 10-band dengan 24 preset
- Playlist dengan album art otomatis
- Background image kustom
- Keyboard shortcut (Space, ←/→, ↑/↓, Esc)
- Tampilan kaset 3D dengan roda berputar
